# Wwiz Seller Rank 설치 가이드

## 준비 사항

| 항목 | 요구 사항 |
|---|---|
| 운영체제 | Windows 10 / 11, 64비트 |
| 디스크 | 여유 공간 2GB 이상 (설치 후 약 600MB) |
| 권한 | 관리자 권한 필요 없음 |
| 별도 프로그램 | 필요 없음. Python·브라우저를 따로 깔지 않아도 됩니다. 화면 표시용 Microsoft WebView2 가 없으면 설치 중에 자동으로 함께 설치됩니다. |
| 인터넷 | 설치·업데이트와 순위 수집에 필요 |

## 내려받기

아래 링크를 누르면 항상 최신 버전 설치 파일을 받습니다.

**https://github.com/wwiz-mublo/wwiz-seller-rank-download/releases/latest/download/WwizSellerRank-Setup.exe**

지난 버전과 바뀐 점은 [릴리스 목록](https://github.com/wwiz-mublo/wwiz-seller-rank-download/releases)에서 볼 수 있습니다.

## 설치 순서

1. 받은 `WwizSellerRank-Setup.exe` 를 실행합니다.
2. **"Windows의 PC 보호" 창이 뜨면** → **추가 정보** → **실행** 을 누릅니다.
   코드 서명 인증서를 아직 쓰지 않아 처음 한 번 나오는 안내이며, 파일이 손상됐다는 뜻은 아닙니다.
3. 설치 위치(기본 `%LOCALAPPDATA%\Programs\Wwiz Seller Rank`)와 바탕화면 바로가기 여부를 고르고 **설치** 를 누릅니다.
4. 마지막 화면에서 **지금 실행** 을 체크한 채 **마침** 을 누릅니다.

> 프로그램이 켜져 있는 상태에서는 설치가 진행되지 않습니다. 트레이(작업 표시줄 오른쪽 아래)의 아이콘까지 종료한 뒤 다시 실행하세요.

## 처음 실행한 뒤

1. **설정 › 네이버 프로필** 에서 순위 수집에 쓸 네이버 프로필을 준비합니다.
2. **설정 › 추적 쇼핑몰** 에 내 쇼핑몰을 등록합니다.
3. 사용 방법은 [사용 가이드](user-guide.md)를 참고하세요.

## 업데이트

- 프로그램을 켤 때와 켜져 있는 동안 6시간마다 새 버전을 확인합니다.
- **설정 › 일반 › 자동 업데이트** 가 켜져 있으면(기본값) 새 버전을 받아 스스로 바꾸고 다시 시작합니다. 수십 초 정도 걸립니다.
- 끄면 사이드바 아래에 **새 버전 X 업데이트** 버튼이 나타나고, 누를 때 설치합니다.
- **설정 › 일반 › 업데이트 확인** 으로 바로 확인할 수도 있습니다.
- 업데이트 파일은 배포자 서명과 SHA-256 해시가 맞을 때만 설치되며, 수집한 데이터는 그대로 남습니다.
- 자동 업데이트가 안 되면 위 설치 파일을 다시 받아 실행하세요. 덮어 설치되며 데이터는 유지됩니다.

## 파일 무결성 확인 (선택)

릴리스마다 `.sha256` 파일이 함께 올라가 있습니다. PowerShell 에서 결과를 비교하세요.

```powershell
Get-FileHash .\WwizSellerRank-Setup.exe -Algorithm SHA256
```

## 제거

**Windows 설정 › 앱 › 설치된 앱 › Wwiz Seller Rank › 제거**

수집한 데이터와 네이버 프로필(`%LOCALAPPDATA%\WwizSellerRank`)은 다시 설치할 때 이어 쓰도록 남겨 둡니다.
완전히 지우려면 제거 후 이 폴더를 직접 삭제하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 설치 파일이 실행되지 않음 | SmartScreen 창에서 **추가 정보 → 실행**. 백신이 막으면 예외로 등록 |
| "프로그램이 실행 중" 이라며 설치가 멈춤 | 트레이 아이콘 우클릭 → 종료 후 다시 설치 |
| 화면이 하얗게 나옴 | WebView2 설치가 실패한 경우. [WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)을 설치한 뒤 다시 실행 |
| 업데이트가 계속 실패 | 설치 파일을 다시 받아 덮어 설치 |
