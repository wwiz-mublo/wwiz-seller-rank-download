# Wwiz Seller Rank 사용 가이드

네이버 쇼핑에서 내 상품이 몇 위에 노출되는지, 가격비교(카탈로그)에서 내 판매처가 몇 번째이고 최저가와 얼마나 차이 나는지를
내 PC 에서 자동으로 추적하는 프로그램입니다. 설치는 [설치 가이드](install-guide.md)를 보세요.

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 추적 중인 키워드·상품의 최근 순위 요약 |
| 인기 키워드 | 내 카테고리의 인기 검색어 순위와 키워드별 클릭 추이 |
| 추적 › 키워드 추적 | 키워드 검색결과에서 내 쇼핑몰 상품이 어디에 노출되는지 |
| 추적 › 개별 상품 추적 | 특정 상품 하나가 지정한 키워드에서 몇 위인지 |
| 추적 › 가격비교 상품 | 카탈로그 안 내 판매처 순위·가격과 최저가 차이, 변동 알림 |
| 추적 › 순위 이력 | 측정한 순위의 변화 기록 |
| 랜딩 모니터 | 상품을 눌렀을 때 내 판매 페이지로 잘 넘어가는지 점검 |
| 작업 로그 | 수집·점검 작업의 실행 기록 |
| 설정 | 일반 · 추적 쇼핑몰 · 알림 · 네이버 프로필 |

모든 시간은 한국 시간(KST)으로 표시합니다. 각 항목 옆 **?** 버튼을 누르면 설명이 나옵니다.

## 처음 설정하기

1. **설정 › 네이버 프로필**
   - **전용 브라우저 설치** 를 먼저 누릅니다(설치본에는 이미 들어 있어 바로 끝납니다).
   - 회원 프로필: 네이버에 로그인한 브라우저로 검색합니다. 로그인 상태는 **세션 확인** 으로 볼 수 있습니다.
   - 비회원 프로필: 로그인 없이 숨김 브라우저로 순위를 검색합니다.
2. **설정 › 추적 쇼핑몰** — **＋ 쇼핑몰 등록** 으로 내 쇼핑몰을 추가합니다.
   - 쇼핑몰명: 검색결과에 표시되는 이름 그대로
   - 대표 도메인·스토어 ID: 선택. 넣으면 더 정확히 찾습니다.
3. **설정 › 일반**
   - wwizseller.kr 계정 로그인(무료): 인기 키워드를 보려면 필요합니다. 비밀번호는 저장하지 않습니다.
   - 네이버 검색광고 API 키(선택): 넣으면 키워드 상세에 실제 월간 검색수를 함께 보여 줍니다.
   - 컴퓨터 시작 시 자동 실행, 자동 업데이트 설정

## 키워드 추적

1. **추적 › 키워드 추적 › ＋ 키워드**
2. 키워드를 넣고, 찾을 쇼핑몰을 한 개 이상 고른 뒤 **키워드 등록**
3. 키워드를 누르면 그 검색결과에서 내 쇼핑몰 상품의 현재 순위·가격비교 순위가 보입니다.

- 활성 키워드는 최대 **10개** 입니다.
- 같은 키워드를 6시간 안에 이미 수집했다면 그 결과를 다시 씁니다.

## 개별 상품 추적

키워드 추적과 별개로, 특정 상품 하나를 정해 두고 순위를 봅니다. 스마트스토어·브랜드스토어·자사몰 모두 가능합니다.

1. **추적 › 개별 상품 추적 › ＋ 상품**
2. 입력 항목

   | 항목 | 설명 |
   |---|---|
   | 쇼핑몰명 | 검색결과에 보이는 쇼핑몰명 |
   | 상품 MID | 숫자 또는 `nvMid=…` 가 들어간 링크 (선택, 넣으면 가장 정확) |
   | 상품명 | 검색결과에 보이는 상품명 그대로 |
   | 랜딩 URL | 상품을 눌렀을 때 도착해야 하는 주소 (랜딩 모니터가 점검) |
   | 추적 키워드 | 상품당 최대 **2개** |

3. 상품 카드의 진행 링이 측정 진행을 보여 주고, 이후에는 자동으로 주기 측정합니다.

- 활성 상품은 최대 **20개** 입니다.
- 키워드마다 6시간 안의 수집 결과에서 먼저 찾고, 없으면 새로 수집합니다.

## 가격비교 상품

내가 판매처로 들어가 있는 가격비교(카탈로그) 페이지를 추적합니다.

1. **추적 › 가격비교 상품 › ＋ 가격비교 상품**
2. 입력 항목

   | 항목 | 설명 |
   |---|---|
   | 카탈로그 ID | `search.shopping.naver.com/catalog/숫자` 주소를 붙여 넣거나 숫자만 |
   | 카탈로그 이름 | 선택. 비우면 수집한 카드 이름으로 채웁니다. |
   | 내 쇼핑몰명 | 판매처 목록에 보이는 이름 그대로 |
   | 판매처 MID | 선택. 같은 이름의 판매처가 여럿일 때 정확히 구분 |
   | 키워드 | 최대 **2개**. **그 카탈로그 카드가 검색결과 5페이지(200위) 안에 나오는 검색어** 여야 합니다. |

3. 키워드 상태가 **가능** 이 되면 **판매처 측정** 으로 바로 읽거나, 하루 한 번 자동 측정을 기다립니다.
4. 결과: 내 판매처 순위, 내 가격(배송비 포함), 최저가, 최저가와의 차이, 판매처 목록

- 가격비교 상품은 최대 **10개** 입니다.
- 안전을 위해 카탈로그 주소로 바로 들어가지 않고, **키워드로 검색 → 카드 클릭** 으로 들어갑니다.
  카드가 5페이지 밖으로 밀리면 키워드 상태가 **키워드 교체 필요** 로 바뀌니 다른 키워드로 바꿔 주세요.

## 알림 (설정 › 알림)

Slack(웹훅 주소) 또는 Telegram(봇 토큰·Chat ID)으로 가격비교 변동을 알려 줍니다. **테스트 알림 보내기** 로 연결을 확인하세요.

알리는 경우:

- 내 가격(배송비 포함)이 최저가보다 **기준 비율(%) 이상** 비싸질 때
- 최저가를 빼앗기거나 되찾을 때 (기준과 상관없이)
- 판매처 순위가 바뀔 때 (기준과 상관없이)
- 판매처 목록에서 내 판매처가 사라질 때 (기준과 상관없이)

## 인기 키워드

1. 판매하는 상품의 1단계 카테고리부터 고르고, 위 단계 선택 상자로 하위 카테고리까지 좁힙니다.
2. 기간을 고르면 인기 검색어 순위와 이전 대비 순위 변동이 나옵니다.
3. 키워드를 누르면 **키워드 인사이트** 창에서 클릭량 추이·기기·성별·연령 그래프를 봅니다.
   - 클릭량은 기간 중 가장 많은 날을 100 으로 둔 상대값이며 실제 검색 횟수는 아닙니다.
   - 검색광고 API 키를 넣었다면 실제 월간 검색수도 함께 보입니다.

wwizseller.kr 로그인이 필요합니다. 하루 단위로 저장해 두므로 같은 날 다시 열면 바로 보입니다.

## 랜딩 모니터

개별 상품에 넣은 랜딩 URL 로, 검색결과에서 상품을 눌렀을 때 그 주소의 도메인으로 잘 넘어가는지 점검합니다.

## 프로그램 닫기와 트레이

창을 닫으면 **트레이로 보낼지** 묻습니다. 트레이로 보내면 백그라운드에서 순위 수집이 계속됩니다.
완전히 끄려면 트레이 아이콘 우클릭 → **종료**.

## 데이터 위치

`%LOCALAPPDATA%\WwizSellerRank` 에 데이터베이스·네이버 프로필이 저장됩니다. 업데이트·재설치해도 유지됩니다.
